CSS Border-Radius

The border-radius property in CSS is used to create rounded corners for HTML elements. It allows you to specify the radius of the element's corners, giving them a softer and more visually appealing appearance. You can apply the border-radius property to various elements, such as divs, images, buttons, and more. The value of border-radius can be specified in different units, such as pixels (px), percentages (%), or ems (em). You can set the same radius for all corners or specify different values for each corner individually.
